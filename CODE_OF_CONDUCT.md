# Community Code of Conduct | 社区行为准则

PairRename welcomes respectful, curious, and constructive participation. Give actionable feedback, assume good faith where possible, and discuss ideas and behavior—not a person's worth or identity.

These expectations apply to project issues, pull requests, code review, and other PairRename community spaces. Harassment, discrimination, threats, doxxing, sexualized attention, and deliberate publication of another person's private information are not acceptable. Do not post private photographs, credentials, signing keys, or sensitive folder contents.

If conduct needs moderator attention, report it privately through GitHub's repository reporting tools. Maintainers may edit or remove harmful content and restrict participation when needed to protect community members.

---

## 中文

PairRename 欢迎尊重、好奇且愿意建设性交流的参与者。请尽量善意理解彼此，提供可执行的反馈；讨论观点与行为，不攻击他人的人格或身份。

本准则适用于项目 Issue、Pull Request、代码评审和其他 PairRename 社区空间。骚扰、歧视、威胁、人肉搜索、性化冒犯，以及故意公开他人的私人信息，都不可接受。请勿发布私人照片、凭据、签名密钥或敏感目录内容。

如果需要版主介入，请通过 GitHub 仓库举报工具私下联系。为保护社区成员，维护者可编辑或移除有害内容，并在必要时限制参与。
