# Security Policy

## Supported version

Security fixes are expected to target the latest published source version. Older builds may not receive fixes; update from a source you trust and keep backups of important files.

## Reporting a vulnerability

Please do not publish an unpatched vulnerability or private photographs in a public issue. Use GitHub's **Report a vulnerability** feature for this repository (Security tab) to send a private report. Include:

- affected version, Android version, and storage provider;
- concise reproduction steps and impact;
- logs or a proof of concept with personal data removed.

If private reporting is unavailable, open a minimal issue asking for a private contact route without including exploit details. Please allow maintainers reasonable time to investigate before public disclosure.

## Scope and safety notes

PairRename can rename, move, organize, or place selected files in its in-app trash. Test with copies, review operation plans, and retain independent backups. The in-app undo/history/trash features are not a substitute for backups. Never send real photo libraries, signing keys, or credentials in a report.
