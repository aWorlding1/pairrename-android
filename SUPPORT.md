# Support

- **Bug report:** open an issue using the bug report template. Include reproducible steps and redact personal data.
- **Feature idea:** use the feature-request template and describe the workflow and why it matters.
- **Security issue:** follow [SECURITY.md](SECURITY.md); do not post exploit details publicly before a fix is available.
- **Usage:** see the bilingual [README](README.md). Try new file operations on copies and keep independent backups.

PairRename is a community project; response times are not guaranteed. Please do not upload private photo libraries, credentials, or signing keys to issues or pull requests.
